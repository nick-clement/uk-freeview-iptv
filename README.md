# UK Freeview-style IPTV playlist

29 UK channels in Freeview numbering, with logos and a 7-day guide.

Playlist URL:
https://raw.githubusercontent.com/nick-clement/uk-freeview-iptv/main/uk-freeview.m3u

Guide data comes from https://github.com/dp247/Freeview-EPG (updated every 12 hours).
Streams come from official broadcaster and platform sources listed in https://github.com/Free-TV/IPTV.
Many BBC streams only work inside the UK.
