# UK Freeview-style IPTV playlist

166 UK channels in Freeview-style numbering, with logos and guide data.

Playlist URL:
https://raw.githubusercontent.com/nick-clement/uk-freeview-iptv/main/uk-freeview.m3u

- BBC channels, including BBC One London, West, South West and Wales, plus BBC Two Wales and S4C
- Free ad-supported UK channels from Samsung TV Plus
- Guide data: https://github.com/dp247/Freeview-EPG and https://github.com/matthuisman/i.mjh.nz
- Stream sources: https://github.com/Free-TV/IPTV and Samsung TV Plus UK

Many streams only work inside the UK.

Guide: `epg.xml` in this repo is rebuilt every 4 hours by a GitHub Action (`build_epg.py`).
